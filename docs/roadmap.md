# Roadmap público

Itens abaixo são propostas, não funcionalidades disponíveis.

## Prioridade alta

- rate limiting;
- circuit breaker;
- métricas Prometheus;
- validação de payload mais completa;
- imagem Docker com hardening adicional;
- testes HTTP end-to-end.

## Evolução

- embeddings;
- cache semântico;
- estratégias por latência e custo;
- tracing;
- múltiplas chaves/tenants;
- políticas de dados por rota.

O roadmap público pode divergir do desenvolvimento privado da plataforma.
